METHOD & LIMITATIONS

Make every finding inspectable.

Choose the transparent RGB baseline or the optional author-trained LEVIR-CD U-Net. Pretrained model scores are uncalibrated, and a model proposal is not verification. Each candidate is challenged using robust registration, global per-channel illumination correction, local edge disagreement, local luminance correlation, and four one-pixel perturbations.

A supported result means it passed these heuristic checks. It is not a calibrated probability or proof of damage. Shadows, vegetation, parallax, cloud, and sensor changes can still fool the system. Image coordinates are pixels, never geographic coordinates or square metres.

Optional Muse Spark interpretation suggests alternatives and additional evidence. Optional SAM 3.1 supplies building masks. Neither silently overrides the measured verdict. A reviewer records their own decision with an append-only audit trail.

The built-in scenes are deterministic procedural illustrations, not benchmark or real disaster images. Use the included benchmark runner with licensed, held-out A/B/label imagery before making accuracy claims.
